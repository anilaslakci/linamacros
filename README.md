# Lina Macros

Frontend-only tek sayfa landing page. Backend, veritabanı veya ödeme entegrasyonu yoktur. Satın alma butonları doğrudan Shopier ürün sayfalarına gider.

## Lokal çalıştırma
Dosyayı doğrudan `index.html` ile açabilir veya VS Code Live Server kullanabilirsiniz.

## GitHub Pages
1. Bu klasörün içeriğini bir GitHub reposuna yükleyin.
2. Settings > Pages > Deploy from a branch seçin.
3. Branch: `main`, klasör: `/ (root)`.
4. Kaydedin.

## Cloudflare Pages
Framework preset: `None`
Build command: boş
Build output directory: `/`
